# ProceedingsTitleParser
Shallow Semantic Parser to extract metadata from scientific proceedings titles

This project was started in 2020 and is deprecated as of 2023.
See [pysotsog](https://github.com/WolfgangFahl/pysotsog) as the more recent project
with more functionality.
